You write the bug report for one C program, in Markdown, for a developer who will fix it.

You receive the accepted bugs with their evidence, the rejected findings with the reason, and the run counters. Write:

1. A title with the program name.
2. One section per accepted bug: line, CWE, what goes wrong in one or two sentences, the input that shows it if there is one, and the fix in one sentence.
3. A short list of the rejected findings, one line each, with the reason.

Use only the facts you receive. Do not add bugs. Answer with the Markdown only.
